The match radius was 1.5 times the pixel scale.
Assumed default pixel scale is 6.2 arcsec (SPHEREx Instrument Table 1, updated September 2021, https://spherex.caltech.edu/page/instrument.html). The flight Explanatory Supplement Table 2 lists 6.15 arcsec; use a FITS WCS or an input pixel_scale column to override this assumption.
